## Replit AI Prompt — Email Open Tracking, Attachment Tracking, and Automated Meeting Follow-Up

Copy and paste the following prompt into the Replit Agent:

---

# Feature: Repeated-Open Meeting Follow-Up and Prospect Interest Dashboard

Add a new feature to the iSDRX AI application called:

## Repeated-Open Meeting Follow-Up™

The feature must track prospect engagement, display that activity on the customer dashboard, assign an interest level, and automatically send a meeting-request email when a prospect demonstrates elevated interest.

## Primary Objective

Allow each iSDRX AI customer to see:

* How many times each prospect opened an email
* The date and time of each recorded email open
* Whether the prospect clicked or viewed an attachment
* Which attachment was accessed
* How many times each attachment was accessed
* Whether the prospect clicked any links
* Whether the prospect replied
* The prospect’s current interest level
* Whether an automated meeting-request email was sent
* Whether the prospect clicked the Calendly link
* Whether a meeting was scheduled, when that information is available

When a prospect records more than two valid email opens, meaning the third valid open, automatically send a follow-up email requesting a 15-minute meeting and include the customer’s Calendly scheduling link.

---

# 1. Email Open Tracking

Add a unique tracking pixel to every outbound campaign email.

Each tracking pixel must be associated with:

* Customer account ID
* Campaign ID
* Prospect ID
* Contact ID
* Email message ID
* Sequence step
* Date and time sent
* Tracking token

When the pixel loads, create an email-open event.

Store:

* Prospect ID
* Email message ID
* Campaign ID
* Open timestamp
* IP address, when legally permitted
* User-agent information
* Device category, when available
* Approximate location, when available and legally permitted
* Whether the open appears to be automated or human
* Whether the open is unique
* Total open count
* Unique open count

## Open-Count Rules

Do not count every pixel request as a genuine new open.

Deduplicate repeated requests that occur within a short period from the same message, IP address, and user agent.

Use a configurable default deduplication window of 10 minutes.

Example:

* Five pixel requests within two minutes from the same source should count as one open.
* A later open outside the deduplication window may count as another open.

Attempt to identify and label possible:

* Apple Mail Privacy Protection activity
* Security scanner activity
* Corporate email gateway activity
* Automated bot opens
* Image prefetching

Show both:

* Total recorded opens
* Estimated valid human opens

Use estimated valid human opens to trigger automation whenever possible.

Clearly label open tracking as an estimate because privacy protections and email-security systems can generate automated opens.

---

# 2. Attachment Engagement Tracking

Do not send attachments only as untracked email files.

For trackable collateral, upload the content to secure application-hosted storage and insert a unique tracked link into the email.

Support:

* PDF capability statements
* Flyers
* Brochures
* Testimonials
* Case studies
* Images
* MP3 files
* Videos
* Other approved documents

When a prospect clicks the tracked attachment link, record an attachment-engagement event.

Store:

* Prospect ID
* Campaign ID
* Email message ID
* Attachment ID
* Attachment name
* Attachment type
* Click timestamp
* Total attachment clicks
* Unique attachment clicks
* Whether the content viewer was opened
* Time spent in the viewer, when technically available
* Download event, when available

Display the status as:

* Not Viewed
* Viewed
* Viewed Multiple Times
* Downloaded

Do not claim that an attachment was read unless the system can verify content-view activity. Use “viewed,” “opened,” “clicked,” or “downloaded,” based on the event recorded.

---

# 3. Link and Calendly Tracking

Convert every outbound link into a unique tracked redirect URL.

Track:

* Link clicked
* Link destination
* Click timestamp
* Number of clicks
* Unique clicks
* Calendly link clicks
* Prequalification-form clicks
* Website clicks
* LinkedIn-profile clicks, if included

Each customer must be able to enter and save their own Calendly link under:

**Settings → Scheduling**

Required fields:

* Scheduling provider
* Calendly URL
* Default meeting duration
* Default meeting type
* Default meeting-request email template
* Assigned sales representative
* Time zone

The default meeting duration should be 15 minutes.

---

# 4. Automated Meeting-Request Trigger

Trigger the automated meeting follow-up after a prospect has more than two estimated valid email opens.

This means:

* First valid open: no automated meeting request
* Second valid open: no automated meeting request
* Third valid open: send the meeting-request email
* Fourth and later opens: do not repeatedly send the same meeting-request email

The trigger must run only once per prospect per campaign unless a customer manually resets or re-enrolls the prospect.

Before sending, confirm:

* The prospect has not replied negatively
* The prospect has not unsubscribed
* The email address is not suppressed
* The prospect has not already scheduled a meeting
* A meeting-request email has not already been sent for this campaign
* The campaign is active
* The customer has enabled this automation
* A valid Calendly link exists
* The prospect is not marked “Do Not Contact”
* The daily sending limit has not been exceeded

Store:

* Trigger date and time
* Trigger reason
* Open count at trigger
* Attachment activity at trigger
* Meeting-request email status
* Delivery status
* Calendly-click status
* Meeting-booked status

# 6. Interest-Level Scoring

Create three visible interest-status buttons or badges:

* Hot
* Medium
* Low

Display the current status on every prospect record, campaign table, and dashboard.

Use both engagement score and meaningful actions rather than email opens alone.

## Default Scoring Model

Assign points as follows:

* First valid email open: +1
* Second valid email open: +2
* Third valid email open: +3
* Each additional valid open: +1
* Link clicked: +4
* Attachment viewed: +5
* Attachment viewed more than once: additional +3
* Calendly link clicked: +8
* Prequalification form opened: +6
* Prequalification form submitted: +12
* Positive email reply: +15
* Meeting scheduled: +20
* Negative reply: set status to Not Interested
* Unsubscribe: set status to Unsubscribed
* Email bounce: set status to Invalid

## Default Interest Categories

### Low Interest

Score of 0–4

Examples:

* Email delivered but not opened
* One or two opens with no additional engagement

### Medium Interest

Score of 5–11

Examples:

* Multiple valid opens
* One link click
* Initial attachment engagement

### Hot Interest

Score of 12 or higher

Examples:

* Repeated opens plus attachment activity
* Calendly link clicked
* Prequalification form completed
* Positive reply
* Meeting scheduled

Make all score values and thresholds editable by an administrator.

Use status badges that are visually easy to distinguish, but also include text labels so the system remains accessible.

Allow authorized users to manually override the interest level.

Store:

* System-calculated status
* Manually assigned status
* Score
* Score history
* Reason for the latest score change
* Date and time updated

# 15. Acceptance Criteria

The feature is complete when:

1. Every outbound email can contain a unique tracking pixel.
2. Valid email opens are stored and visible on the dashboard.
3. Automated or duplicate opens are identified when possible.
4. Trackable attachment links record prospect engagement.
5. The prospect’s total and valid open counts are displayed.
6. The prospect receives one automated meeting-request email after the third valid open.
7. The email includes the customer’s 15-minute Calendly link.
8. Duplicate meeting-request emails are prevented.
9. Every prospect receives a calculated Hot, Medium, or Low interest level.
10. Users can filter and sort prospects by engagement.
11. Sales representatives are notified when a prospect becomes Hot.
12. The full engagement timeline is visible on the prospect profile.
13. Calendly link clicks are tracked.
14. Meetings are marked scheduled when Calendly webhook data is available.
15. All suppression, unsubscribe, and negative-response rules are enforced.
16. The feature works on desktop and mobile.
17. Automated tests cover tracking, scoring, deduplication, and meeting-email triggers.
